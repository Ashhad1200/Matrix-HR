# MatrixHR — Video & content kit

Source material for explainer videos and social content. All facts match the shipped product.

| File | What it is | Use it for |
|---|---|---|
| `00-SYSTEM-EXPLAINER.md` | Full plain-language explanation of the whole system | **Primary NotebookLM source.** Upload this for the Audio/Video Overview. Also the briefing doc for any video. |
| `01-YOUTUBE-FULL-SCRIPT.md` | Scene-by-scene narrated long-form script (~13–16 min) | The full YouTube product tour. VISUAL + VO per scene; includes a 6-min short cut and a white-label cut. |
| `02-LINKEDIN-SHORTS.md` | 20 vertical short scripts (25–45s each) | LinkedIn/X/Reels/TikTok. Each has hook, script, on-screen beats, CTA and a ready post caption. |

## Using these with NotebookLM
1. Upload `00-SYSTEM-EXPLAINER.md` (and optionally `01-...` and the landing copy) as sources.
2. For the long video: generate a **Video Overview**, or feed `01-YOUTUBE-FULL-SCRIPT.md` as the narration and record screen capture to match each scene's VISUAL.
3. For shorts: each numbered block in `02-...` is a self-contained script — record screen B-roll for the on-screen beats and read the script.

## Guardrails (keep it honest)
- No invented customer names, logos or statistics.
- Any tax/EOBI/PF figure gets the caption **"Confirm current rates with your advisor."**
- The **Activity Monitor** is always presented as **disclosed and consent-first** — never as covert surveillance. That's how it's built; keep the messaging matched.
- For a reseller/white-label cut, swap the brand name, logo and colour and drop the vendor name.
